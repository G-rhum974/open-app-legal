Support utilisateur

Cette page permet de contacter le support de l'application OPEN Profils Croisés pour un problème technique, une question, un signalement ou une demande liée aux données personnelles.

Email support : j.imaze730@gmail.com

1. Problème technique

Pour signaler un problème technique, envoyez un email avec :

  • votre adresse e-mail liée au compte ;
  • le modèle de votre appareil ;
  • la version iOS utilisée ;
  • une description claire du problème ;
  • une capture d'écran si possible.

2. Signalement

L'application permet de signaler directement un message, une conversation ou un comportement suspect.

3. Blocage

Si un utilisateur vous dérange, utilisez la fonction de blocage disponible dans l'application.

4. Suppression du compte ou des données

Pour demander la suppression de votre compte ou de vos données personnelles, contactez : j.imaze730@gmail.com.
